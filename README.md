# Svetainės

# Apie projektą:

# Tai mokomasis gidas, skirtas supažindinti su HTML ir CSS pagrindais. Projektą sukūrė G.J. (2 kurso, 1 grupės studentas) Informacijos pateikimo internete technologijos kursui. Jis skirtas bendrakursiams, studentams ir visiems, kurie domisi interneto technologijomis.

# 

# Kaip paleisti projektą kompiuteryje:

# 

# 1\. Atsisiųskite ir išskleiskite ZIP failą į norimą aplanką.

# 2\. Atsidarykite pagrindinį failą index.html savo naršyklėje.

# 3\. Norėdami redaguoti kodą, atidarykite failus su Notepad++ arba Visual Studio Code.

# 

# Projekto struktūra:

# 

# \* index.html – Pradinis puslapis su įvadu ir atsiliepimų forma.

# \* pages/ – Aplankas su teorija bei pavyzdžiais: HTML pagrindai, CSS pagrindai, galerija ir darbo eigos ataskaita.

# \* css/styles.css – Pagrindinis failas, kuris viską stilizuoja.

# \* Kiti aplankai: Vieta nuotraukoms.

# 

# Techniniai sprendimai:

# 

# \* Struktūra: Panaudoti semantiniai žymėjimai (header, nav, main, article, footer ir kt.) bei tvarkinga antraščių hierarchija.

# \* Dizainas: Puslapio išdėstymui ir galerijai naudotas Flexbox, o spalvos bei tarpai suderinti per kintamuosius (:root).

# \* Pritaikomumas: Veikia visuose ekranuose, o visi paveikslėliai turi aprašymus (alt tekstus).

# 

# Testavimas ir žinomi trūkumai:

# 

# \* CSS: Visi stiliai sėkmingai praėjo validaciją!

# \* Trūkumai: Ilgas, gali būt nepatikrintų JavaScript bugs
