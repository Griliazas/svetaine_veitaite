Kodą galima rašyti tiesiai tarp <script>, bet geriau jį laikyti kitame .js faile ir prijungti per src atributą (kaip ir CSS).

Mygtukas ir onclick

Copy mygtukas yra paprastas <button> elementas su klase copy-btn!

Atributas onclick nurodo, kokį JS metoda naudot, kai mygtukas paspaudžiamas.

this rodo patį paspaustą mygtuką. this matėme ir su java. Tai yra kontekstas, funckija žino kuris mygtukas iškvietė. Kažkas tokio.


<div class="code-container">

    <pre><code>
    &lt;h1&gt;Sveikas&lt;/h1&gt;
    </code></pre>

    <div class="copy-container">
        <button class="copy-btn" onclick="copyCode(this)">Kopijuok!</button>
    </div>

</div>
Dalis Ka ji dirba? :O
class="code-container" Div (prašau nebauskit už div), turi ir kodą, ir mygtuką. Pagal jį funkcija randa, kurį kodą kopijuoti. Šį karta div labai labai labai svarbus buvo.
<pre><code> Pats kodas, kuris bus nukopijuotas.
class="copy-btn" Klasė mygtuko stiliui! Dėl jos jis labai labai gražus.
onclick="copyCode(this)" Paspaudus iškviečia funkciją su kontekstu . Krc jo.

Svarbu, kad mygtukas ir kodas abu turi būti viename code-container, kitaip funkcija būtų durna ir dėl to buvo labai daug problemų prašau nedaryti mano klaidų...


Visa funkcija

Čia yra visa funkcija iš button_logic.js. Išnagrinėsime frame by frame >:]


async function copyCode(button) {
    const container = button.closest(".code-container");
    const code = container.querySelector("code").innerText;

    try {
        await navigator.clipboard.writeText(code);

        const originalText = button.innerText;
        button.innerText = "Nukopijuotas!";

        setTimeout(() => {
            button.innerText = originalText;
        }, 1500);

    } catch (err) {
        console.error("Nepavyko nukopijuoti:", err);
        alert("Nepavyko nukopijuoti kodo :(( ");
    }
}

TLDR; funkcija suranda kodą div, nukopijuoja jį į clipboard, trumpam pakeičia mygtuko tekstą į „Nukopijuotas!“.


function, async ir await

Skliaustuose esantis button yra parametras :] Čia tai paspaustas mygtukas (kurį perdavėme per this) ir vėl kontekstas gal per daug kartoju save.

async reiškia, kad funkcija gali laukt lėtos durnos iškarpinės, nesustabdydama viso puslapio.

await Laukia. The one who waits. Jį galima naudoti tik viduje async funkcijos.


async function sveikinti(vardas) {
    await kazkasLetas();
    console.log("Labas, pasauli, mano vardas " + vardas);
}

Async reiks navigator.clipboard.writeText negrąžina rezultato iškart, o pažada, kad kada nors baigs darbą. Panašiai kaip aš pažadu grąžint pinigus Benediktui, kažkada bus. await palaukia to pažado.


closest ir querySelector

JavaScript gali matyt HTML elementus ir jų ieškoti. Nepasislėpsite nuo šios negražios kalbos.

Kodas Ka jis dirba? :O
button.closest(".code-container") Pradeda nuo mygtuko ir eina per parent elementus, kol randa code-container.
container.querySelector("code") Eina per container vidų ir randa <code> elementą.
.innerText Elemento matomas tekstas be durnų HTML žymių. Tie kas žino.
const Sukuria kintamąjį, nu visose kalbose const yra aš jum rato neišradinėsiu. 

const container = button.closest(".code-container");
const code = container.querySelector("code").innerText;

Dėl šio būdo vienas funkcijos kodas veikia su visais mygtukais puslapy ir kituose kur yra script link.

Mygtuko tekstas ir setTimeout

Pirmiausia išsisaugome pradinį tekstą kintamajame, kad vėliau galėtume jį grąžinti.

setTimeout(funkcija, milisekundės) paleidžia funkciją po nurodyto laiko :]/p>

button.innerText = "Nukopijuotas!";

    button.innerText = originalText;

Problema Skill issue / sprendimas
Mygtukas nieko nedaro Patikrink, ar <head> yra teisingas <script src> kelias, ir ar konsolėje (F12) nėra raudonų klaidų.
Klaida „Cannot read properties of null“ Mygtukas nėra viduje code-container arba šalia nėra <code> elemento.
Iššoka alert „Nepavyko nukopijuoti“ Naršyklė neleido pasiekti iškarpinės. Atidaryk svetainę per https arba localhost.
Nukopijuotas kodas turi per daug tarpų pradžioje <pre> išsaugo visus tarpus
