CSS

Šiame puslapyje išmoksite CSS.

HTML sukuria puslapio griaučius, o CSS juos nudažo ir kartais padaro gražesnius. Visi pavyzdžiai čia paimti iš tikro šios svetainės styles.css failo :]


Kaip prijungti CSS

CSS (Cascading Style Sheets) yra stiliaus kalba. Ją prie HTML galima prijungti trimis būdais.

BūdasKur rašoma?Kada naudoti?
Išorinis failas<link rel="stylesheet" href="styles.css"> viduje <head>Beveik visada! Vienas failas stilizuoja visus puslapius.
Vidinis<style>...</style> viduje <head>Kai stilių reikia tik vienam puslapiui.
Eilutinis (inline)style="..." atributas elementeGreitam vienkartiniam pakeitimui, nedaryk to durniau.

Šioje svetainėje naudojamas išorinis failas, jis prijungtas kiekvieno puslapio <head> dalyje: 


                    <link rel="stylesheet" href="../css/styles.css">

Vidinio ir eilutinio pavyzdžiai: 


                    <style>
                        p {
                            color: hotpink;
                        }
                    </style>

                    <p style="color: hotpink;">Ružavas... mmmmm... </p>

CSS sintaksė

CSS taisyklė susideda iš selektoriaus ir deklaracijų bloko. 


                    selektorius {
                        savybė: reikšmė;
                        kita-savybė: kita reikšmė;
                    }

Taip atrodo pati paprasčiausia taisyklė šios svetainės CSS nes aš labai kieta ir per daug prirašiau kitur prašau padėkit: 


                    p {
                        font-size: 20px;
                    }

                    h1 {
                        color: #ecbdff;
                    }

Čia visų <p> elementų šriftas bus 20 pikselių, o visų <h1> antraščių spalva bus ružava.


Kaskada

Kas nutinka, jei dvi taisyklės stilizuoja tą patį elementą?

1. Konkretesnis selektorius laimi: id (#) stipresnis už klasę (.), o klasė stipresnė už elementą.

2. Jei specifiškumas vienodas, laimi taisyklė, parašyta vėliau faile. Įdomiai veikia ane. 


                    /* viena iš svetainės taisyklių visoms nuorodoms */
                    a {
                        color: #151b2e;
                    }

                    /* konkretesnė taisyklė viršuje esančioms nuorodoms */
                    .top-nav a {
                        color: #cdbdff;
                    }

Nors a taisyklė nurodo tamsią spalvą, nuorodos viršutinėje navigacijoje yra šviesios, nes .top-nav a yra konkretesnis selektorius :O


Selektoriai

Selektorius sako naršyklei, kuriuos elementus stilizuoti. Žemiau yra visi, kuriuos naudoju šioje svetainėje.

Gera taisykle rašyti kiek įmanoma bendresnius stilius, labai vargau keičiant spalvas.

SelektoriusKą renkas valentinui?Pavyzdys
pVisus tokio tipo elementus (elemento selektorius).p { font-size: 20px; }
.klasėVisus elementus su tokia class="klasė"..copy-btn { cursor: pointer; }
#idVieną elementą su tokiu id (naudoju retai, nes jie unikalūs).#intro { ... }
*Absoliučiai visus elementus.* { box-sizing: border-box; }
a, bGrupavimas: abu selektoriai gauna tą patį stilių.html, body { margin: 0; }
a bPalikuonis: b viduje a (bet kokiame gylyje).article section h2 { ... }
a.klasėElementą a, kuris turi ir tą klasę (be tarpo!)..top-nav a.active { ... }
 

                    <!-- HTML -->
                    <button class="copy-btn">Kopijuok!</button>

                    /* CSS */
                    .copy-btn {
                        padding: 8px 16px;
                        background-color: #151b2e;
                        color: #d9ccff;
                        font-weight: bold;
                        border: 2px #9d8ce0 solid;
                        border-radius: 5px;
                        cursor: pointer;
                        font-size: 14px;
                    }

Taip atrodo grupavimas ir palikuonio selektoriai iš šios svetainės: 


                    html, body {
                        margin: 0;
                        padding: 0;
                        height: 100vh;
                        overflow: hidden;
                        background-color: #0a0c14;
                    }

                    article section h2 {
                        color: #ecbdff;
                    }

                    .side-nav a:hover,
                    .side-nav a.active {
                        background-color: #cdbdff;
                        color: #151b2e;
                    }

Spalvos

Spalvas CSS galima rašyti keliais būdais: pavadinimu (red, hotpink), hex kodu (#ecbdff) arba rgb (rgb(236, 189, 255)).

Hex kodai net nelyginamai geriausias pasirinkimas net ne=inau ką darot be jų.

color keičia teksto spalvą, o background-color keičia fono spalvą. Šios svetainės paletė:

SpalvaKodasKur ikišau?
Waow#0a0c14Viso puslapio fonas (body).
Waow#151b2eHeader fonas, mygtukai.
Waow#1a2036Pagrindinis turinys (article).
Waow#262e4aŠoninė navigacija ir aside.
Waow#9d8ce0Footer, rėmeliai.
Waow#cdbdffNuorodos, hover fonas.
Waow#ecbdffAntraštės ir kodas.

Pavyzdys iš CSS: 


                    header {
                        background-color: #151b2e;
                        color: #cdbdff;
                    }

                    header h2 {
                        color: #ecbdff;
                    }

Tekstas ir šriftai

SavybėKą dirba?Pavyzdys
font-familyŠrifto šeima. Šioje svetainėje visur math.font-family: math;
font-sizeTeksto dydis.font-size: 20px;
font-weightTeksto storis (normal, bold).font-weight: bold;
colorTeksto spalva.color: #ecbdff;
text-alignTeksto lygiavimas (left, center, right).text-align: center;
text-decorationPabraukimas. none panaikina nuorodų pabraukimą.text-decoration: none;

Taip aprašytos viršutinės navigacijos nuorodos: 


                    .top-nav a {
                        display: inline-block;
                        padding: 10px 20px;
                        color: #cdbdff;
                        text-decoration: none;
                        font-weight: bold;
                        border-radius: 10px;
                    }

Taip visai svetainei nustatytas šriftas: 


                    * {
                        box-sizing: border-box;
                        font-family: math;
                    }

Dėžutės modelis (box model)

Kiekvienas HTML elementas CSS akimis yra dėžutė. Ji turi keturis sluoksnius iš vidaus į išorę:

SluoksnisKą daro?
contentPats turinys (tekstas, vaizdas).
paddingTuščia vieta viduje, tarp turinio ir rėmelio.
borderRėmelis aplink padding.
marginTuščia vieta išorėj.

Pavyzdys!!! (ružavas rėmelis, padding viduje ir margin išorėje):

Waow (๑˃ᴗ˂)ﻭ

                    <div style="border: 2px solid #9d8ce0; padding: 20px; margin: 20px;">
                        Waow
                    </div>

Savybes galima rašyti ir trumpiau, pavyzdžiui padding: 10px 20px; reiškia 10px viršuje ir apačioje, 20px kairėje ir dešinėje.

Dar vienas svarbus dalykas yra border-radius, kuris suapvalina kampus, ir box-sizing: border-box, dėl kurio width apima padding ir border, tad elementai nebeišlenda iš savo rėmų. Todėl jį duodu visiems elementams: 


                    * {
                        box-sizing: border-box;
                    }

                    pre code {
                        background-color: #0d1020;
                        border: 2px solid #9d8ce0;
                        padding: 13px;
                        border-radius: 2px;
                    }

Matavimo vienetai

VienetasKą daro pituhas?Pavyzdys iš šios svetainės
pxPikseliai, fiksuotas dydis.font-size: 20px;
%Procentai nuo tėvinio elemento dydžio.width: 100%;
vhViewport height: 1vh yra 1% ekrano aukščio.height: 100vh;
frGrid vienetas: dalis laisvos vietos.minmax(0, 1fr)
calc()Leidžia skaičiuoti, net maišyti vienetus.calc(100vh - 160px)

Dabartinė šio puslapio aukščio formulė, kuri leidžia pagrindiniam turiniui užimti visą ekraną, išskyrus fiksuotą header ir footer: 


                    .page-layout {
                        height: calc(100vh - 160px); /* ekrano aukštis minus viršaus ir apačios plotai */
                    }

display

display nusako, kaip elementas elgiasi puslapyje.

ReikšmėKą daro?
blockPrasideda naujoje eilutėje, užima visą plotį (div, p, h1).
inlineTelpa eilutėje, neturi plotio ir aukščio (span, a).
inline-blockTelpa eilutėje, bet leidžia nustatyti padding, width ir height.
flexVaikus išrikiuoja eilute ar stulpeliu (flexbox).
gridVaikus išdėlioja į lentelę, kurią pats suprojektuoji (grid).
noneVisiškai paslepia elementą.

Pavyzdys: viršutinės navigacijos nuorodos pagal nutylėjimą yra inline, todėl joms duotas inline-block, kad veiktų padding: 


                    .top-nav a {
                        display: inline-block;
                        padding: 10px 20px;
                    }

Flexbox

display: flex; paverčia elementą flex konteineriu. Jo vaikai išsirikiuoja į eilutę (arba stulpelį) ir juos lengva centruoti ar paskirstyti.

SavybėKą daro?
flex-directionKryptis: row (eilutė, nutylėjimas) arba column (stulpelis).
justify-contentIšdėsto vaikus pagrindine ašimi: center, space-evenly, flex-end...
align-itemsIšdėsto vaikus skersine ašimi: center, flex-start...
flex-wrapLeidžia vaikams persikelti į kitą eilutę, kai neužtenka vietos.
gapTarpas tarp vaikų.

Taip aprašyta viršutinė navigacija: 


                    .top-nav {
                        display: flex;
                        justify-content: center;
                        align-items: center;
                        flex-wrap: wrap;
                        gap: 13px;
                    }

Čia nuorodos sustatytos į eilutę, centre, su 13 pikselių tarpais, o ant siauro ekrano persikelia į kitą eilutę. Footer naudoja tą patį triuką: 


                    footer {
                        display: flex;
                        justify-content: space-evenly;
                    }

                    .copy-container {
                        display: flex;
                        justify-content: flex-end;
                    }

space-evenly vienodai išdėsto vaikus visame plote, o flex-end prispaudžia mygtuką "Kopijuok!" prie dešiniojo krašto.


Grid

display: grid; dalija elementą į stulpelius ir eilutes. Tinka visam puslapio išdėstymui, o flexbox daugiau tinka vienai eilutei ar stulpeliui.

grid-template-columns nurodo stulpelių plotį, o gap tarpą tarp jų. Dar svarbi funkcija minmax(min, max), kuri nurodo, kad stulpelis negali būti siauresnis už min ir platesnis už max.

minmax(0, 1fr) Be jo plati kodo eilutė galėtų išstumti visą stulpelį ir sugadinti puslapį. 


                    .page-layout {
                        display: grid;
                        grid-template-columns: 210px minmax(0, 1fr) 210px;
                        gap: 13px;
                    }

Čia šoninė navigacija yra 210px, aside yra 210px, o turinys užpildo visą tarpą. Siaurinant ekraną grid keičiamas media query taisyklėmis (apie jas toliau): 


                    @media (max-width: 900px) {
                        .page-layout {
                            grid-template-columns: 180px minmax(0, 1fr);
                        }

                        aside {
                            grid-column: 2;
                        }
                    }

position

position nusako, kaip elementas yra išdėstomas puslapyje.

ReikšmėKą daro?
staticElementas yra įprastoje vietoje.
relativeElementą galima pastumti nuo jo įprastos vietos (top, left...).
absoluteElementas pozicionuojamas pagal artimiausią pozicionuotą tėvą.
fixedElementas prikabintas prie ekrano ir nejuda slenkant.
stickySlenka kartu su puslapiu, kol pasiekia nurodytą vietą, tada prilimpa.

Šios svetainės header ir footer yra fixed: jie visada matomi viršuje ir apačioje. top, left ir bottom nurodo atstumą nuo ekrano krašto, o z-index užtikrina, kad jie būtų virš viso kito turinio. 


                    header {
                        width: 100%;
                        position: fixed;
                        top: 0;
                        left: 0;
                        z-index: 1000;
                    }

                    footer {
                        width: 100%;
                        position: fixed;
                        bottom: 0;
                        left: 0;
                        z-index: 1000;
                    }

Fixed elementai nebeužima vietos puslapyje, todėl body gavo padding-top ir padding-bottom, kad turinys nepasislėptų po jais: 


                    body {
                        padding-top: 100px;
                        padding-bottom: 40px;
                    }

overflow ir slinkimas

overflow nurodo, ką daryti, kai turinys netelpa į dėžutę.

ReikšmėKą daro?
visibleNutylėjimas, turinys išlenda už dėžutės ribų.
hiddenNepatelpantis turinys paslepiamas.
autoSlinkties juosta atsiranda tik jei jos reikia.
scrollSlinkties juosta rodoma visada.

Šioje svetainėje visas puslapis užrakintas (overflow: hidden), o slenka tik pagrindinis turinys. Labai stengiaus VU bibliotekoj 


                    html, body {
                        height: 100vh;
                        overflow: hidden;
                    }

                    main {
                        height: 100%;
                        overflow-y: auto;
                    }

                    .side-nav {
                        height: 100%;
                        overflow-y: auto;
                    }

overflow-y valdo tik vertikalų slinkimą, o overflow-x horizontalų. Šitaip aprašyti kodo blokai, kad ilgos eilutės slinktų į šoną ir neišlįstų iš dėžutės: 


                    pre {
                        max-width: 100%;
                        overflow-x: auto;
                    }

O šita eilutė padaro, kad paspaudus nuorodą į sekciją puslapis nušoka gražiai: 


                    html {
                        scroll-behavior: smooth;
                    }

Hover ir animacijos (transition)

Pseudo-klasė :hover suveikia, kai užvedi pelę ant elemento. Pridedama prie selektoriaus per dvitaškį, ir tada galima pakeisti elemento išvaizdą. 


                    .top-nav a {
                        background-color: transparent;
                        color: #cdbdff;
                        transition: background-color 0.2s, color 0.2s;
                    }

                    .top-nav a:hover {
                        background-color: #cdbdff;
                        color: #1a2036;
                    }

Pabandyk užvesti pelę ant bet kurios viršuje esančios nuorodos ar mygtuko "Kopijuok!". Kitos naudingos pseudo-klasės yra :active, :focus, ir :first-child. Kopijavimo mygtukui hover aprašytas taip: 


                    .copy-btn:hover {
                        background-color: #0d1020;
                    }

Media query (responsive dizainas)

@media taisyklės leidžia pritaikyti puslapį skirtingiems ekranams: kompiuteriui, planšetei ar telefonui. Viduje esantis CSS veikia tik jei sąlyga tenkinama. 


                    /* planšetė */
                    @media (max-width: 900px) {
                        .page-layout {
                            grid-template-columns: 180px minmax(0, 1fr);
                        }

                        aside {
                            grid-column: 2;
                        }
                    }

                    /* telefonas */
                    @media (max-width: 600px) {
                        .page-layout {
                            grid-template-columns: minmax(0, 1fr);
                            gap: 16px;
                        }

                        header h2 {
                            font-size: 24px;
                        }

                        .top-nav a {
                            padding: 8px 12px;
                        }
                    }

Čia PC yra trys stulpeliai, planšetėje du, o telefone vienas. Kad tai veiktų, HTML <head> turi būti ši eilutė: 


                    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Pabandyk keisti naršyklės lango dydį ir pamatysi, kaip ši svetainė prisitaiko :D


Slinkties juostos stilius

Scrollbar taip pat galima nudažyti, naudojant pseudo-elementus ::-webkit-scrollbar. Jie veikia Chrome, Edge ir Safari naršyklėse.

Pseudo-elementasKą stilizuoja?
::-webkit-scrollbarVisą juostą (pavyzdžiui jos plotį).
::-webkit-scrollbar-trackTakelį, kuriuo juda slankiklis.
::-webkit-scrollbar-thumbPatį slankiklį.
 

                    ::-webkit-scrollbar {
                        width: 10px;
                    }

                    ::-webkit-scrollbar-track {
                        background: #151b2e;
                    }

                    ::-webkit-scrollbar-thumb {
                        background: #9d8ce0;
                    }

                    ::-webkit-scrollbar-thumb:hover {
                        background: #cdbdff;
                    }

Taip atsirado violetinė slinkties juosta dešinėje :]


Komentarai

CSS komentaras rašomas tarp /* ir */. Žinot jau kas tie komentarai 


                    /* tai komentaras */
                    p {
                        font-size: 20px; /* komentaras gali būti ir eilutės gale */
                    }

                    /* h1 {
                        color: red;
                    } */
