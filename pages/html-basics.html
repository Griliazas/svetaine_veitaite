HTML

Šiame puslapyje išmoksite HTML.


<!DOCTYPE html> ir <html>

<!DOCTYPE html> ir <html> abu nurodo Hyper Text Markup Language.

<!DOCTYPE html> nurodo, jog blank.html (šablonas bet kokiam .html failui) yra HTML5 dokumentas.

<html> yra sakninis elementas puslapiui, jame turi būti visi kiti elementai.


<head> ir <body>

<head> ir <body> sudaro <html> griaučius.

<head> yra skirtas metaduomenims - visai nematomai puslapio informacijai;

<body> yra skirtas visam matomam svetainės turiniui. 


                    <!DOCTYPE html>
                    <html>
                    <head>
                    <title>Labai gražus pavadinimas</title>
                    </head>
                    <body>

                    <h1>Sveikas</h1>
                    <p>Pasauli!</p>

                    </body>
                    </html>

Paaiškinimas


Taip atrodo <head> sekcija šios svetainės HTML: 


                    <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>veitaite</title>
                    <link rel="stylesheet" href="../css/styles.css">
                        <script src="../scripts/button_logic.js"></script>
                    </head>

<head>

<header> yra blokas skirtas informacijai puslapio viršuje, kaip svetainės pavadinimui.

Header taip pat dažnai sujungiamas su nav!


                    <header>
                    <h1>Labai geras pavadinimas!</h1>
                    </header>

Taip atrodo <header> blokas šios svetainės HTML: 


                    <header>
                    <h2>Bombinis svetainių pradžiamokslis</h2>

                    <!-- nav header -->
                    <nav class="top-nav" aria-label="Pagrindinė navigacija">
                        <a href="../index.html">Namai</a>
                        <a href="../pages/html-basics.html">HTML</a>
                        <a href="../pages/css-basics.html">CSS</a>
                        <a href="../process.html">Procesas</a>
                        <a href="../pages/javascript-basics.html"> JS </a>
                        <a href="../pages/gallery.html"> Galerija </a>
                    </nav>
                    </header>

Mano svetainės header turi h2 antraštę pavadinimui ir nav (navigaciją) skirtingiems puslapiams.

Apie nav rašysiu kitame šio puslapio skyrelyje :]


<nav> , <li> ir <a href>

<nav> yra HTML layout blokas skirtas nuorodoms arba kitiems puslapiams, arba sekcijom to pačio puslapio.

<li> yra elementas nurodantis sąrašo eilutę. Sarašai gali būti nenumeruoti <ul> ir numeruoti <ol>

<a href=""> yra nuorodų atributas, kuris gali būti pritaikomas beveik visur. Jis gali nurodyti i URL, kitą dokumentą puslapių struktūroje, sekcijas tame pačiame dokumente. href taip pat naudojamas vaizdams. 


                        <nav>
                        <ul>
                            <li><a href="../pages/html-basics.html">Puslapis</a></li>
                            <li><a href="#id_section">Sekcija</a></li>
                            <li><a href="www.google.com">Url</a></li>
                        </ul>
                        </nav>
